# RCA Checklist

- [ ] What was the user-visible symptom?
- [ ] What shared function/component/data path caused it?
- [ ] Which callers or workflows also touch that path?
- [ ] What evidence proves the root cause?
- [ ] What is the smallest fix at the shared cause?
- [ ] What regression check fails before the fix and passes after?
- [ ] What logging, test, or instruction would have caught it earlier?
- [ ] Should the lesson be promoted to project, stack, or enterprise guidance?
