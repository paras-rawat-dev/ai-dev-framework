# UI Member Selection Checklist

Use this before adding UI libraries to a project.

- [ ] Product shape is clear: dashboard, admin, SaaS, content site, prototype, design system.
- [ ] Primary UI member is selected.
- [ ] Secondary allowed libraries are named.
- [ ] Forbidden overlapping libraries are named.
- [ ] Accessibility requirements are explicit.
- [ ] Theming strategy is explicit.
- [ ] Table/chart/form needs are known.
- [ ] Mobile/responsive expectations are known.
- [ ] Browser verification path is defined.

Recommended defaults:

- Custom Tailwind app: shadcn/ui + Radix.
- Fast internal app: Mantine.
- Dense enterprise admin: Ant Design or MUI.
- Analytics dashboard: Tremor plus the primary UI member.
- Design-system foundation: Radix Primitives.
- Polished Tailwind app: HeroUI.
