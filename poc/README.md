# Small POC

This POC checks whether the framework improves project readiness for a tiny AI-assisted build.

It compares:

- [baseline-output.md](baseline-output.md): a loose prompt-style project plan.
- [framework-output.md](framework-output.md): the same tiny project using the framework templates.

Run:

```bash
python3 tools/score_poc.py
```

This is intentionally a static readiness check, not a claim that an LLM produced better code. To test real agent behavior, replace the two output files with artifacts generated by the same agent with and without the framework, then rerun the scorer and inspect the resulting code manually.
