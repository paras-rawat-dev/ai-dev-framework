# Project Kickoff Reference

Create these files in a new project:

- `PROJECT_CHARTER.md`
- `ARCHITECTURE.md`
- `TESTING.md`
- `AI_WORKFLOW.md`
- `AGENTS.md`

Minimum questions:

1. What are we building and why?
2. Who uses it?
3. What is out of scope?
4. Which stack packs apply?
5. Is there UI work, and which UI member should be used?
6. What data sources are involved?
7. What checks prove work is done?
8. What areas require independent review?

If the user does not know a non-critical answer, choose a conservative default and mark it as an assumption.
