# Existing Project Reference

For an existing repo:

1. Inspect files, package manifests, tests, docs, and current instruction files.
2. Document current reality.
3. Create minimal project docs only from evidence.
4. List gaps separately from confirmed facts.
5. Avoid broad refactors during onboarding.

Useful first output:

```text
Confirmed:
- stack:
- test commands:
- UI library:
- data sources:

Missing:
- project charter
- testing policy
- AI workflow

Recommended next action:
- create minimal AGENTS.md and PROJECT_CHARTER.md
```
