# Governance

This framework is owned by engineering leadership, but the content should be written by the people closest to the work.

## Ownership

| Area | Owner |
| --- | --- |
| Enterprise constitution | engineering leadership |
| Security and data rules | security / platform / data governance |
| Stack packs | tech leads |
| Project charters | project tech lead |
| Personal instructions | individual developer |
| POC scoring rubric | framework maintainers |

## Change Rules

- Enterprise rules require review from the owning function.
- Stack packs require review from at least one practitioner of that stack.
- Project rules require review from the project tech lead.
- Personal templates can change freely, but examples must not contradict project or enterprise guidance.

## Versioning

Use simple semantic versions for the framework:

- major: structural change to levels or adoption flow
- minor: new stack pack, checklist, or integration guide
- patch: wording, examples, or small rule clarifications
